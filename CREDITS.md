# Credits

GT Arcade is a learning project. Each game is built by following a tutorial and then extended with original changes. Credit goes to the original tutorial authors.

## Tutorials

## Original work

Changes beyond the tutorials (visuals, naming, extra features) are listed in each game's own `CREDITS.md`.

Game titles in this repository are original names; the underlying game ideas (such as Pong) are classics.
