# Thunderlight Ping Pong

A Pong game. The player faces a CPU paddle, both sides score, and the ball resets after each point.

## Versions

| Version | Folder | Status |
|---|---|---|
| Python + Pygame | [python/](python/) | Playable (0.2.0) |
| C++ + Raylib | `cpp/` | Planned |

## Planned twist

A CPU paddle with selectable difficulty levels (a PID-controlled paddle is the idea to explore).

## Shared assets

Sounds, fonts and images used by every version go in [assets/](assets/).
