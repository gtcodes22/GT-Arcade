# Roster

Public titles are original names. Each game is built following a tutorial and then extended with one signature twist.

| Public title | Classic | Languages | Status | Twist (proposed) |
|---|---|---|---|---|
| Thunderlight Ping Pong | Pong | Python, then C++ | Python in progress | CPU paddle with difficulty levels (PID control) |
| Snake | Snake | Python, then C++ | Planned | Pathfinding autoplay mode |
| Tetris | Tetris | Python, then C++ | Planned | Ghost piece and hold slot |
| Space Invaders | Space Invaders | Python, then C++ | Planned | Boss wave or wave editor |
| Asteroids | Asteroids | JavaScript | Planned | Neural-network autopilot |
| 2048 | 2048 | JavaScript | Planned | A teach mode showing powers of 2 |
| Rock Paper Scissors | Rock Paper Scissors | JavaScript | Optional | To decide |

Titles other than Thunderlight Ping Pong are working names and may be renamed before release.
